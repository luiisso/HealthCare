# Mi Programa de Peso
Web estática (GitHub Pages) + Worker de Cloudflare (gratis) con la API gratuita de Gemini para la cámara y las analíticas.
Archivos: index.html, estilos.css, app.js (web) · worker.js (va a Cloudflare, no a Pages).
Pasos completos: ver la respuesta del chat. Cambia API_URL en app.js por la URL de tu Worker.

Fotos de recetas: sube el .jpg al repositorio y pon su nombre en el campo f de cada receta en app.js.
